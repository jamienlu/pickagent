## response api

1. Response、Output Item、Content Item 分别负责什么？

   1. resopnse是一次完整的模型响应,包含 sataus,output,usage

   2. output item是output数值中的每一个元素可能是文本，工具调用，图像生成请求等

   3. content item 是message类型的output的组成部分，负责图集内容片段，支持多模态输出

2. 为什么 Response 和 Message 都可能有自己的 `status`？

多层级追踪和错误隔离，单个输出项文本函数调用等部分失败

3. 新出现一种 Output Item 时，Java 程序应该如何降级处理？

自定义UnkownHander处理器，记录日志提取通用字段等，保留数据原始结构，本次结果不处理这部分数据，正常执行其余数据项，生产配备异常数据告警。
