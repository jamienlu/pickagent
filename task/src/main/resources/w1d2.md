## response api

1. Response、Output Item、Content Item 分别负责什么？

   1. resopnse是一次完整的模型响应,包含 sataus,output,usage

   2. output item是output数值中的每一个元素可能是文本，工具调用，图像生成请求等

   3. content item 是message类型的output的组成部分，负责图集内容片段，支持多模态输出

2. 为什么 Response 和 Message 都可能有自己的 `status`？

多层级追踪和错误隔离，单个输出项文本函数调用等部分失败

## response body param

> [https://developers.openai.com/api/reference/resources/responses/methods/create](https://developers.openai.com/api/reference/resources/responses/methods/create)
1. model 

   1. model id

   2. ResponseCreateParams.builder().model(model)

   3. 不同模型功能特性不同价格不同

2. input

   1. optional string or array of [EasyInputMessage](https://developers.openai.com/api/reference/resources/responses#(resource)%20responses%20%3E%20(model)%20easy_input_message%20%3E%20(schema)) or object or [ResponseOutputMessage](https://developers.openai.com/api/reference/resources/responses#(resource)%20responses%20%3E%20(model)%20response_output_message%20%3E%20(schema)) or 29 more Text, image, or file inputs to the model, used to generate a response

   2. ResponseCreateParams.builder().input(input)

   3. string 等于 user角色，构造其他类型的input要设置role和content等

3. instructions 

   1. A system (or developer) message inserted into the model’s context.

   2. ResponseCreateParams.builder().instructions(instructions )

   3. previous_response_id使用时这个只对当前响应有用不会带入先一个

4. max_output_tokens

   1. including visible output tokens and [reasoning tokens](https://developers.openai.com/docs/guides/reasoning)

   2. ResponseCreateParams.builder().maxOutputTokens(max_output_tokens)

5. previous_response_id

   1. Use this to create multi-turn conversations

   2. ResponseCreateParams.builder().previousResponseId(previous_response_id)

   3. Cannot be used in conjunction with `conversation`

6. store

   1. Whether to store the generated model response for later retrieval via API

   2. ResponseCreateParams.builder().store(true)

   3. 模型生成的响应存在服务端要提供给下次调用使用否则不能使用previous_response_id

7. stream

   1. If set to true, the model response data will be streamed to the client。

   2. client.responses().createStreaming()

   3. 确保应用服务支持流式输出在能在openai调用的时候传递响应

8. text

   1. Configuration options for a text response from the model. Can be plain text or structured JSON data. Learn more:

   2. ResponseCreateParams.builder().text(text)

   3. 确保是需要喂给模型的数据不然增加token
