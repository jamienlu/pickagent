# ADR-0006：离线验证边界

[English](0006-offline-verification-boundary.md) | [简体中文](0006-offline-verification-boundary.zh-CN.md)

- 状态：已接受
- 日期：2026-09-08

## 背景

默认测试必须快速、确定、无需凭据，并可安全重复运行。SDK fixture 可以验证 adapter 行为，但不能证明真实 OpenAI 服务的属性。

## 决策

使用离线测试作为默认质量门。它们验证：

- API 值对象不变量和不可变快照。
- Agent 生命周期、步骤预算、重复调用停止和带类型失败。
- SDK 边界上的严格 Schema 映射。
- 协议解析、`call_id` 往返和 reasoning 条目保留。
- 完整批次预检、有序串行执行和失败停止。
- 重试延迟计算和本地幂等规则。

这些测试不能证明：

- 真实模型质量、可用性、延迟、计费、额度或 Schema 一致率。
- 代理、TLS、超时或真实网络上的流式行为。
- 除已安装版本代码路径外的 SDK 自动重试交互。
- 分布式幂等、崩溃恢复或副作用 exactly-once。
- 应用授权或审批策略。

未来加入实时集成测试时，必须使用独立标签、显式开关、专用凭据和成本控制。

## 影响

- `mvn test` 可复现且不需要 OpenAI API Key。
- 可执行演示是离线协议证明，不是实时服务兼容性证据。
- 生产就绪还需要独立的集成与评估层。
