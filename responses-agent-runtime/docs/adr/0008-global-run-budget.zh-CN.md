# ADR-0008：全局运行预算

[English](0008-global-run-budget.md) | [简体中文](0008-global-run-budget.zh-CN.md)

- 状态：已接受
- 日期：2026-09-09

## 背景

单个 response 的输出上限与 SDK 请求超时无法约束多轮模型/工具循环。即使每个请求都合法，发生循环的模型仍可能继续消耗调用、执行更多副作用，或超过应用截止时间。

## 决策

每次 `AgentRuntime` 运行都拥有不可变 `RunBudget`，包含最大模型调用数、最大应用工具调用数和可选单调时钟截止时间。Runtime 在模型请求前检查预算，并在工具副作用前再次检查。预期的预算耗尽返回稳定停止原因，而不是抛出异常。

所有正常终态——完成、停止、模型失败、工具失败——都携带不可变 `RunUsage` 快照。截止时间使用可注入 `NanoClock`，使测试确定且不受墙上时钟变化影响。旧版最大步骤构造器映射到新预算以保持兼容。

## 后果

- 调用数和副作用上限覆盖整次运行，而不是单个 response。
- 运维可以区分模型调用数、工具调用数和截止时间停止。
- usage 统计 Runtime 逻辑调用，不包含 SDK 内部重试尝试或供应商 Token 用量。
- Token 和金额预算仍是未来扩展，需先定义明确的供应商中立 usage 契约。

## 验证

单元测试覆盖校验、精确边界、截止时间、各类终态快照、重复调用、失败和不可变结果集合。JaCoCo 强制完整行与分支覆盖。
